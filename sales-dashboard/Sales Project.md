# Global Sales Performance Dashboard

This Power BI project was designed for a fictional international company to analyze sales performance, profitability, customer segments, discount impact, and monthly trends.

## Objectives
- Identify the most profitable products and segments
- Evaluate the impact of discounts on profit margins
- Detect seasonal sales patterns
- Support business decision-making through interactive dashboards

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Features
- Multi-page dashboard design
- Interactive slicers and navigation
- KPI tracking
- Profitability analysis
- Trend analysis
